# Pães Catarina
Cardápio responsivo em Next.js, React, Tailwind CSS e Lucide React.

## Desenvolvimento
npm ci
npm run dev

## Validação
npm run typecheck
npm run build

## Publicação
Importar o repositório paes-catarina na Vercel, com framework Next.js e diretório raiz.
A branch main publica em produção; outras branches geram prévias.
As imagens são ilustrativas. O contato comercial é configurado em app/page.tsx.
